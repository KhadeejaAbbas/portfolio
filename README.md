# 🌲 Interactive 3D Portfolio

An interactive portfolio built with **Three.js** where visitors explore a 3D world instead of scrolling through a traditional website.

Guide a bear through forests, cafés, markets, and project areas to discover my projects, research, and experiences.

## ✨ Features

- 🐻 Third-person character controller
- 🌍 Interactive 3D environment
- 🎒 Inventory system
- 🍎 Collectible fruit
- 🛒 Market for selling collected items
- ☕ Café with purchasable drinks
- 📖 Interactive project popups
- 🎵 Sound effects and animations
- 🌳 Custom environment created in Blender

---

## 🛠 Built With

- Three.js
- JavaScript (ES6 Modules)
- HTML5
- CSS3

- GSAP

## 🚀 Running the Project

Clone the repository:

```bash
git clone https://github.com/KhadeejaAbbas/portfolio.git
```

Open the project with a local web server.

For example:

- VS Code Live Server
- Python HTTP Server
- Any static web server

If using Python:

```bash
python3 -m http.server
```

Then open:

```
http://localhost:8000
```

## 🎮 Gameplay

Explore the world and interact with different locations.

### 🍎 Collect Fruit
Gather apples, mangoes, and tomatoes while exploring.

### 🎒 Inventory
Track:
- Coins
- Drinks
- Apples
- Mangoes
- Tomatoes

### 🛒 Market
Sell collected fruit to earn coins.

### ☕ Café
Purchase drinks using coins you've earned.

### 📚 Projects
Walk up to project displays to learn more about my work through interactive popups.
